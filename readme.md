# 野生動物制御システム PoC (warden_poc)

本システムは、Dockerコンテナ上で動作する基地局（Gateway）のリアルタイム監視GUIマップと、複数の首輪端末（Collar）シミュレータ間でTCP通信を行い、野生動物の位置情報（NMEAデータ）や個体属性を統合管理・エリア判定する実証実験（PoC）用アプリケーションです。

## 🛠 動作環境・前提条件

本システムはDockerコンテナ上でGUI（Tkinter）アプリを起動するため、ホストOS（Windows）側で画面を表示する設定が必要です。

1. **Docker Desktop** のインストールと起動
2. **VcXsrv (XLaunch)** のインストール（WindowsでGUIを表示するために必要）

## ⚙️ 事前準備：VcXsrv の起動設定

Windows上でGUI画面をコンテナから転送・表示させるため、あらかじめVcXsrvを起動してください。

1. スタートメニューなどから **`XLaunch`** を起動します。
2. ディスプレイ設定画面: **`Multiple windows`** を選択して「次へ」
3. クライアント起動画面: **`Start no client`** を選択して「次へ」
4. 追加設定画面: **`Disable access control`**（アクセスコントロールの無効化）に**必ずチェックを入れて**「次へ」
5. 「完了」を押すと、タスクトレイにXマークのアイコンが常駐します。

## 🚀 実行手順

### 1. リポジトリのクローン

ターミナル（PowerShell等）を開き、プロジェクトをクローンして移動します。

```bash
git clone https://github.com/あなたのユーザー名/warden_poc.git
cd warden_poc
```

### 2. Docker コンテナのビルド & 起動

#### 【パターン A】 基本起動（基地局 1台 ＋ 首輪端末 1台）

```bash
docker compose up --build
```

#### 【パターン B】 複数首輪の同時検証（例：首輪端末を 3台 同時起動）

`--scale collar=台数` オプションを付与することで、複数の首輪端末ウィンドウを同時に立ち上げてテストできます。

```bash
docker compose up --build --scale collar=3
```

* ※起動後、各首輪端末の画面で「首輪ID（例: `BEAR-001`, `BEAR-002`）」を個別に書き換えて送信することで、基地局側のマップおよび一覧テーブルに複数の個体がリアルタイムで更新・表示されます。

### 3. 各画面での操作

* **基地局画面（Gateway）**: Googleマップベースのリアルタイム監視マップと、受信データ・アクティブ首輪一覧・拠点設定タブが表示されます。
* **首輪端末画面（Collar）**:
  1. 「首輪ID」を個体ごとに変更（例: `BEAR-001`、`BEAR-002` など）。
  2. 属性（性別、年齢等）や「送信NMEA（GPS位置）」を設定・選択。
  3. 「基地局へ属性＆GPS送信」をクリックすると、該当の首輪端末データが基地局マップ上にピン留め・表示されます。

### 4. 終了方法

プログラムを終了する場合は、起動したターミナルで `Ctrl + C` を押すか、別のターミナルで以下のコマンドを実行してコンテナを停止します。

```bash
docker compose down
```
